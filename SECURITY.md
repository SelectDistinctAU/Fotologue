# Security Policy 🔒

## Supported Versions

Fotologue actively maintains and issues security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

Fotologue is a **100% local-first, privacy-by-design** application that operates entirely on-device with zero user account requirements, zero telemetry, and zero remote database servers.

If you discover a potential security vulnerability (such as a local file permission issue or cryptographic backup concern), please report it responsibly:

1. **Email**: Send vulnerability details to [security@selectdistinct.au](mailto:security@selectdistinct.au).
2. **GitHub Private Disclosure**: Alternatively, use GitHub's Security Advisory Private Disclosure feature on our repository: [`SelectDistinctAU/Fotologue`](https://github.com/SelectDistinctAU/Fotologue/security/advisories).

### What to Include in Your Report:
- A description of the issue and its potential security impact.
- Step-by-step instructions or proof-of-concept code to reproduce the issue.
- The platform affected (Android Mobile, Windows Desktop, Linux, or macOS).

### Response Timeline:
- **Acknowledgment**: Within 48 hours.
- **Assessment & Fix**: Security patches are issued as priority updates within 7 days.
