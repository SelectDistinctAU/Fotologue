## 🛠️ Community & Issue Reporting

If you encounter a bug, missing camera/lens preset, or feature request:

1. **GitHub Issues**: Search or submit a new ticket on our GitHub Repository:
   👉 [`SelectDistinctAU/Fotologue Issues`](https://github.com/SelectDistinctAU/Fotologue/issues)
2. **Preset Requests**: Request new camera bodies, lenses, chemistry, or films via GitHub Issues or submit a PR using the Maintainer Tool (`./gradlew :desktop:runMaintainer`).
